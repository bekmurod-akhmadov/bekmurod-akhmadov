## Process

1. **Understand** — clarify the business workflow, user roles, constraints, and edge cases.
2. **Design** — define data relationships, API contracts, and access rules.
3. **Build** — implement focused components and explicit business logic.
4. **Verify** — check critical paths, validation, permissions, and integration failures.
5. **Improve** — investigate bottlenecks, refine queries, and refactor with purpose.
